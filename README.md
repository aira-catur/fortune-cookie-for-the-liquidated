A single fortune cookie line for a crypto trader who just got liquidated: it sounds like a real fortune and lands as a joke on the loss.

See the [Fortune Cookie for the Liquidated bounty on make.fun](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c) for the full rules and leaderboard.

Run it with `python3 main.py`; it writes the fortune to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`).
